RHCOS AMIs for the AWS infrastructure

Red Hat provides Red Hat Enterprise Linux CoreOS (RHCOS) AMIs that are valid for the various AWS regions and instance architectures that you can manually specify for your Red Hat OpenShift Container Platform nodes. RHCOS AMIs are available based on RHEL 9 and RHEL 10.

By importing your own AMI, you can also install to regions that do not have published RHCOS AMIs.
